# Topi Surya IoT

Proyek perangkat topi berkipas yang tenaganya berasal dari panel surya. Repositori ini akan berisi web server untuk memantau dan mengendalikan perangkat, firmware untuk mikrokontroler ESP32, dan simulator agar sisi perangkat lunak bisa diuji tanpa perangkat keras.

## Fitur

Fitur berikut masih berupa rencana dan belum diimplementasikan:

- Dashboard web untuk melihat status perangkat dan data sensor
- Pengiriman data dari ESP32 ke server secara berkala
- Pengaturan mode kipas dari halaman web
- Simulator data sensor untuk pengujian tanpa perangkat keras

## Teknologi

Rencana teknologi yang akan dipakai:

- Next.js untuk web server dan dashboard
- ESP32 dengan firmware berbasis Arduino untuk perangkat keras
- Komunikasi data melalui HTTP API

## Status

Proyek dalam pengembangan. Kode utama belum masuk ke repositori ini. Dokumentasi instalasi dan cara menjalankan akan dilengkapi setelah kode tersedia.
